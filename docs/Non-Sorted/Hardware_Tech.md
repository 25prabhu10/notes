# Hardware Tech

## Digital Interfaces

### Audio and Video Interfaces

- **USB (Universal Serial Bus)**: A standard for connecting peripherals to computers and other devices. It supports data transfer and power supply.
- **HDMI (High-Definition Multimedia Interface)**: A standard for transmitting high-definition video and audio from a source device to a display or audio system.

  - HDMI Audio Return Channel (ARC) allows audio to be sent back from a display to an audio system, eliminating the need for a separate audio cable.

- **DisplayPort**: A digital display interface used to connect a video source to a display device. It supports high resolutions and refresh rates.
  - usb type-c with displayport alternate mode allows for video output over a USB-C connection, enabling the use of displayport features without needing a separate displayport connector
  - Daisy chaining allows multiple displays to be connected in series using a single displayport output, reducing cable clutter and simplifying multi-monitor setups

- **Thunderbolt**: A high-speed interface that combines data, video, and power in a single connection. It is commonly used for connecting external displays, storage devices, and other peripherals.
- **VGA (Video Graphics Array)**: An older analog video interface used for connecting monitors to computers. It has been largely replaced by digital interfaces like HDMI and DisplayPort.
- **DVI (Digital Visual Interface)**: A video interface that supports both digital and analog signals. It is commonly used for connecting monitors to computers.

### Storage and Expansion Interfaces

- **SATA (Serial ATA)**: A standard for connecting storage devices like hard drives and solid-state drives to a computer's motherboard. It supports high data transfer rates and is widely used in modern computers.
- **PCIe (Peripheral Component Interconnect Express)**: A high-speed interface used for connecting expansion cards, such as graphics cards, sound cards, and network cards, to a computer's motherboard. It provides fast data transfer rates and is commonly used in gaming and professional workstations.
- **M.2**: A form factor for internal expansion cards and solid-state drives (SSDs). It is commonly used in laptops and small form factor devices due to its compact size and high performance.
- **NVMe (Non-Volatile Memory Express)**: A protocol for accessing high-speed storage devices, such as NVMe SSDs, over the PCIe interface. It provides low latency and high throughput, making it ideal for gaming, content creation, and other demanding applications.
- **SCSI (Small Computer System Interface)**: An older interface used for connecting storage devices and peripherals to computers. It has been largely replaced by newer interfaces like SATA and NVMe but is still used in some enterprise environments for high-performance storage solutions.
- **FireWire (IEEE 1394)**: A high-speed interface used for connecting digital video cameras, external hard drives, and other peripherals to computers. It has been largely replaced by USB and Thunderbolt but is still used in some professional video applications.
- **Ethernet**: A standard for wired networking that allows devices to communicate over a local area network (LAN). It supports high data transfer rates and is commonly used in homes, offices, and data centers for internet connectivity and file sharing.
