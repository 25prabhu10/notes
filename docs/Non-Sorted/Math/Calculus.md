# Calculus

Calculus is the mathematical study of change. It has two main branches: differential calculus and integral calculus. Differential calculus deals with the concept of the derivative, while integral calculus deals with the concept of the integral

## Pre-Calculus

Pre-calculus is a course that prepares students for calculus. It covers topics such as functions, trigonometry, and algebraic manipulation. Pre-calculus is typically taken in high school or as a prerequisite for calculus in college

### Functions

A function is a relation between a set of inputs and a set of possible outputs where each input is related to exactly one output. Functions can be represented in various ways, such as algebraic expressions, tables, or graphs

Definition: A function is correspondence between input numbers (x-values) and output numbers (y-value) that sends each input number (x-value) to exactly one output number (y-value).

- Sometimes, a function is described with an equation

_Example:_ `y = x^2 + 1`, which can also be written as `f(x) = x^2 + 1`

- What is `f(2)`? `f(2) = 2^2 + 1 = 5`
