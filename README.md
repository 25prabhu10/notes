# Notes

An anthology of code snippets and programming notes collected for reference and learning

## Overview

This repository contains a curated collection of programming snippets, solutions to common problems, and useful techniques across various languages and technologies

## Structure

- Organized by language/technology
- Each snippet includes explanations and usage examples
- Focus on practical implementations and solutions

## Usage

Browse through the collection by navigating to specific language or concept directories

- `pnpm run fetch` runs the cross-platform sync workflow
- `pnpm run deploy` runs fetch + build + deploy
